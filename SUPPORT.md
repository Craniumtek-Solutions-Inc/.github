# Support

For general information about Craniumtek Solutions Inc., visit https://www.craniumtek.com.

For business inquiries or non-security questions, contact **admin@craniumtek.com**.

For repository-specific technical questions, use the issue tracker only when that repository permits public support requests. Please include the repository name, expected behavior, actual behavior, environment, and relevant logs with secrets removed.

For security vulnerabilities, do not open a public issue. Follow [`SECURITY.md`](SECURITY.md).

Craniumtek cannot guarantee support for archived, experimental, educational, or research repositories unless the repository explicitly states otherwise.
