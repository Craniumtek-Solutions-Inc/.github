# Craniumtek Solutions Inc. — GitHub Community

This repository contains the public GitHub organization profile and default community health files for **Craniumtek Solutions Inc.**

It is intentionally limited to public-safe information such as contribution guidance, security reporting, issue and pull-request templates, repository naming conventions, and a high-level portfolio map.

Sensitive infrastructure, server inventories, credentials, deployment procedures, internal security architecture, incident runbooks, and private product strategy do **not** belong in this repository.

See [`profile/README.md`](profile/README.md) for the public organization profile.
